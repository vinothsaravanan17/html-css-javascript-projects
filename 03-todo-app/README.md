# Vanilla JS To-Do App

A clean, modern, and fully functional To-Do application built entirely with vanilla HTML, CSS, and JavaScript. This project demonstrates core DOM manipulation, event handling, and utilizing browser local storage.

## Features

*   **Add Tasks:** Easily add new tasks to your list.
*   **Mark as Complete:** Click on any task text to toggle its completion status. Completed tasks are visually struck through.
*   **Delete Tasks:** Remove unwanted tasks using the dedicated delete button.
*   **Data Persistence:** Tasks are automatically saved to your browser's `localStorage`, meaning your list remains intact even if you refresh or close the page.
*   **Keyboard Accessibility:** Press the "Enter" key while in the input field to quickly add tasks.
*   **Responsive Design:** Centered, clean UI that looks great on any screen size.

## Technologies Used

*   **HTML5:** For the structure and layout.
*   **CSS3:** For styling, utilizing Flexbox for layout and clean, modern colors/transitions.
*   **Vanilla JavaScript (ES6+):** For all application logic, DOM manipulation, and state management without the need for external libraries or frameworks.

## How to Run Locally

Since this is a vanilla frontend project, no build tools or servers are required.

1.  **Clone or Download:** Download the project files (`index.html`, `style.css`, and `script.js`) into a single folder on your computer.
2.  **Open:** Simply double-click the `index.html` file to open it in your default web browser.
3.  **Alternatively:** You can drag and drop the `index.html` file into an already open browser window.

## Project Structure

*   `index.html`: The main HTML document containing the structure.
*   `style.css`: Contains all the styling rules for the application.
*   `script.js`: Contains the JavaScript logic for handling tasks and local storage.
